Designed with a **pure black computer workstation aesthetic** featuring WebGL 3D neural networks, hardware-accelerated 3D perspective card tilts, and comprehensive academic grounding.

## 🌟 Key Highlights

- **Pure Black Workstation UI**: CRT scanline simulation, subtle computational grid overlays, and telemetry header.
- **Interactive 3D Holographic Portrait**: Hardware-accelerated 3D WebGL/CSS perspective tilt, drag-to-rotate physics, and biometric HUD.
- **Interactive 3D Neural Core**: Three.js WebGL centerpiece with physics-based drag-to-rotate interaction, dual wireframe/solid render modes, and orbital telemetry satellites.
- **3D Particle Constellation**: Ambient Three.js background constellation that moves smoothly with mouse parallax.
- **Curriculum Vitae Source of Truth**: 100% grounded in verified academic achievements, projects, publications, and coursework.
- **Custom Branding**: Fully configured for `ankanadas.com` and `ankanadas06.github.io/ankana-portfolio/`.

## 🚀 Quick Start (Local Development)

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or pnpm

### Installation
\\\ash
# 1. Clone or navigate to the project directory
cd ankana-3d-portfolio

# 2. Install dependencies
npm install

# 3. Start local development server
npm run dev
\\\
Visit **http://localhost:3000** in your browser.

---

## 📦 Production Build

To compile an optimized, minified production build:
\\\ash
npm run build
\\\
The build output will be placed in the \dist/\ directory, ready to be deployed on any static web host.

---

## 🌐 Deployment Guide

### Option A: Deploy to Vercel (Recommended - 1 Click)
1. Push this repository to your GitHub account:
   \\\ash
   git remote add origin https://github.com/AnkanaDas06/ankana-portfolio.git
   git branch -M main
   git push -u origin main
   \\\
2. Go to [vercel.com](https://vercel.com) and log in with GitHub.
3. Click **Add New...** -> **Project**, select \nkana-portfolio\, and click **Deploy**.
4. In Project Settings -> **Domains**, add your custom domain: \nkanadas.com\.

### Option B: Deploy to GitHub Pages
1. Install \gh-pages\:
   \\\ash
   npm install --save-dev gh-pages
   \\\
2. Add the following to \package.json\:
   \\\json
   "scripts": {
     "predeploy": "npm run build",
     "deploy": "gh-pages -d dist"
   }
   \\\
3. Run:
   \\\ash
   npm run deploy
   \\\

### Option C: Deploy to Netlify
1. Drag and drop the \dist/\ folder directly into [app.netlify.com/drop](https://app.netlify.com/drop), or connect your GitHub repository for automated continuous deployment.
